# Superstore-Sales-Data-Analysis
## Project Overview
This project analyzes retail sales data to identify patterns and insights related to customers, products, regions, sales, profitability, and shipping performance. The project shows an end-to-end data analytics workflow using Excel, SQL Server, and Power BI.
## Tools for Analysis
- Microsoft Excel
- SQL Server
- Power BI
## Project Objectives
- Clean and prepare retail sales data
- Generate actionable business insights
- Analyze sales and profitability
- Examine shipping performance
- Analyze customer and order performance
- Identify high- and low-performing products and regions
- Develop an interactive Power BI dashboard
